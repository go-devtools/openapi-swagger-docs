## Procedure

1. Record CLI version, command, target, build tags, stdout, stderr and exit code.
2. Read diagnostic `code`, `severity`, `source`, `route`, `facts` and `fix`.
3. Compare source types, actual codec and declarations. Fix inaccurate metadata or add a tested public extension.
4. Regenerate; check complete generated bytes; validate actual positive/negative samples.

## Actions

| Diagnostic | Action |
| --- | --- |
| `openapi.generate.stale` | Regenerate; never edit generated bytes. |
| `openapi.comment.type` | Reconcile the declaration with the wire type. |
| `gin-swagger.handler.ambiguous` | Obtain identity evidence before setting Bindings. |
| `gin-swagger.routes.stale` | Restore a current original route snapshot. |
| Reference/budget error | Supply explicit offline resources or a bounded budget; do not return partial success. |

`CheckWithOptions` accepts `BaseURI`, `Resources` and `ExampleResources`. Never fetch missing references automatically. Source freshness, document validity and runtime agreement are separate claims. Preserve `implementation: "not-proven"`; selected routes must still pass Build.
